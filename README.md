
# Smart Wildlife Monitoring and Threat Analysis System

## Overview

An AI-powered wildlife monitoring project using deep learning and YOLO11s for detecting and analyzing wildlife.

## Project Objectives

- Detect wildlife species from images and videos.
- Apply deep learning-based object detection.
- Evaluate model performance.
- Explore wildlife monitoring and threat analysis.

## Technologies Used

- Python
- PyTorch
- Ultralytics YOLO11s
- OpenCV
- Google Colab
- Jupyter Notebook
