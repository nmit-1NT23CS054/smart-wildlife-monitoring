
# Smart Wildlife Monitoring and Threat Analysis System

## Overview

An AI-powered wildlife monitoring project using deep learning and YOLO11s for detecting and analyzing wildlife.

## Project Objectives

- Detect wildlife species from images and videos.
- Apply deep learning-based object detection.
- Evaluate model performance.
- Explore wildlife monitoring and threat analysis.

## Technologies Used

- Python
- PyTorch
- Ultralytics YOLO11s
- OpenCV
- Google Colab
- Jupyter Notebook

## Dataset

- Total images: 1,504
- Training images: 1,203
- Validation images: 150
- Testing images: 151
- Classes: Buffalo, Elephant, Rhino, Zebra

## Model Performance

YOLO11s evaluation on the test dataset:

| Metric | Score |
|---|---:|
| Precision | 96.57% |
| Recall | 88.22% |
| mAP50 | 93.55% |
| mAP50-95 | 80.66% |

## Wildlife Monitoring Features

- YOLO11s wildlife detection
